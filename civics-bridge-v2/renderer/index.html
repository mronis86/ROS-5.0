Civics Bridge V2

Waits for a push from the Companion buttons tab, then draws those pictures and sends them to Companion. This app does not talk to vMix.

Companion buttons

Set the Companion page here. Version 2.4 uses page and bank. Bank 1 is the first button on that page. Version 3 and 5 use page, row, and column. Turn on Companion’s HTTP API. A push from the website is the only time buttons are created or replaced.

Files are 01.png through 10.png. Still-in pictures are transparent and do not change the Companion background. Eliminated pictures are filled grey.
