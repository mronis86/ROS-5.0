# Offline Show (bundled in Offline Kiosk V2)

This is a **copy** of the sibling `ROS-5.0/offline-show` engine, owned by the kiosk package for show-system installs.

- Original sibling folder is left alone.
- To refresh from the sibling: from `offline-kiosk-v2`, run `npm run sync:offline-show`.
- Runtime data stays local under `data/` (gitignored).
